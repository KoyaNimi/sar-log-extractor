# sar-log-extractor

## 概要
サーバーエンジニアの業務としてログ解析を行っています。  
sarコマンドで出力したsaDDファイルから必要なカラムのみを抽出する機会がありました。

sample-sarは複数のセクション（CPU / DEV / IFACE など）を含んだ sar コマンド出力のサンプルです。  
各セクションには独自のヘッダーがあり、1ファイルに複数の形式のデータが混在する構造になっています。

extract_sar.ps1はこの構造のファイルに対応しています。  
複数のsarファイルをまとめて処理できるのがメリットとなります。  

**元ファイルは変更されずそのまま残るためご安心ください。**  

ソースコードを確認し、必要に応じてfixし、ご利用ください。

## 準備
### ディレクトリ構成
C:\My Scripts  
  ┝ extract_sar.ps1  
  ┝ sar_files ・・・ 事前に処理の対象となるsarファイルを格納  
  ┝ output    ・・・ 出力先フォルダ。処理を終えたファイルが自動格納  

### sarファイル格納
sar_filesに処理をかけるsarファイルをすべて格納してください。  
サフィックスは.txt想定です。  

## 実行
powershellで下記を実行ください。
```
cd C:\My Scripts
.\extract_sar.ps1
````
outputフォルダに処理されたファイルが格納されます。
